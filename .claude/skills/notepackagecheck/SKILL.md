## Overview

Given the Excel file path produced by `/notelistextractor`, this skill:
1. Reads all note numbers from column B (skipping the header)
2. Opens each note in SAP for Me and clicks the **Software Components** tab
3. Checks whether **S4CORE 109** (= SAP S/4HANA 2023) is listed as a supported package
4. Writes `Yes` or `No` into a new **"S4 Core 109 Supported"** column in the same Excel file

---

## Step 1 — Read note numbers from the Excel file

Run this Python script to extract the note list and print it:

```python
import openpyxl

path = r"<EXCEL_FILE_PATH>"   # replace with the path the user gave
wb = openpyxl.load_workbook(path)
ws = wb.active

notes = []
for row in ws.iter_rows(min_row=2, values_only=True):
    note_number = str(row[1]).strip() if row[1] else ""
    if note_number and note_number.isdigit():
        notes.append(note_number)

print(notes)
```

Run:
```
python read_notes.py
```

Keep this list — you will visit each note in Steps 2-3.

## Step 2 — Add the new column header to the Excel file

The existing columns are:
| A | B | C | D |
|---|---|---|---|
| # | Note Number | Note Title | SAP for Me Link |

Add the new column **E** header now (before visiting notes):

```python
import openpyxl
from openpyxl.styles import Font, PatternFill, Alignment

path = r"<EXCEL_FILE_PATH>"
wb = openpyxl.load_workbook(path)
ws = wb.active

# Write header for new column E
header_cell = ws.cell(row=1, column=5, value="S4 Core 109 Supported")
header_cell.font = Font(bold=True, color="FFFFFF")
header_cell.fill = PatternFill("solid", fgColor="4472C4")
header_cell.alignment = Alignment(horizontal="center", vertical="center", wrap_text=True)
ws.column_dimensions["E"].width = 22

wb.save(path)
print("Header added.")
```

## Step 3 — For each note, check Software Components in SAP for Me

Attach to the existing authenticated Edge session first (do this once):
```
playwright-cli attach --cdp=msedge
```

Then for **each note number** in the list from Step 1, run these checks in sequence:

### 3a — Open the note
```
playwright-cli goto https://me.sap.com/notes/<NOTE_NUMBER>
playwright-cli snapshot
```

### 3b — Click the Software Components tab
```
playwright-cli click "getByText('Software Components')"
playwright-cli snapshot
```

If the tab label is different (e.g. "Support Packages", "Valid Releases"), click whichever tab shows component/version data.

### 3c — Check for S4CORE 109
```
playwright-cli eval "Array.from(document.querySelectorAll('*')).filter(el => el.childElementCount === 0 && /S4CORE[\s_\-]*109|S\/4HANA[\s_\-]*2023/i.test(el.textContent)).map(el => el.textContent.trim()).slice(0, 5)"
```

- Result is **non-empty** → `S4 Core 109 Supported = Yes`
- Result is **empty array `[]`** → `S4 Core 109 Supported = No`

Record the result for this note, then move to the next note.

## Step 4 — Write results back to the Excel file

After checking all notes, run this Python script to fill column E:

```python
import openpyxl

path = r"<EXCEL_FILE_PATH>"

# results dict: { "note_number": "Yes" or "No" }
results = {
    "1234567": "Yes",
    "1234568": "No",
    # … fill from Step 3
}

wb = openpyxl.load_workbook(path)
ws = wb.active

for row in ws.iter_rows(min_row=2):
    note_cell = row[1]   # column B
    result_cell = row[4] # column E
    note_number = str(note_cell.value).strip() if note_cell.value else ""
    if note_number in results:
        result_cell.value = results[note_number]

wb.save(path)
print(f"Updated: {path}")
```

Run:
```
python write_results.py
```

## Step 5 — Apply conditional formatting (optional but recommended)

Run this to colour the E column: green for Yes, red for No:

```python
import openpyxl
from openpyxl.styles import PatternFill, Font
from openpyxl.formatting.rule import CellIsRule

path = r"<EXCEL_FILE_PATH>"
wb = openpyxl.load_workbook(path)
ws = wb.active

last_row = ws.max_row
green = PatternFill("solid", fgColor="C6EFCE")
red   = PatternFill("solid", fgColor="FFC7CE")
green_font = Font(color="276221")
red_font   = Font(color="9C0006")

ws.conditional_formatting.add(
    f"E2:E{last_row}",
    CellIsRule(operator="equal", formula=['"Yes"'], fill=green, font=green_font)
)
ws.conditional_formatting.add(
    f"E2:E{last_row}",
    CellIsRule(operator="equal", formula=['"No"'],  fill=red,   font=red_font)
)

wb.save(path)
print("Formatting applied.")
```

## Tips

- S4CORE 109 = SAP S/4HANA 2023 on-premise. Accept any of: `S4CORE 109`, `S4CORE109`, `SAP S/4HANA 2023`.
- If the Software Components tab is not visible, try clicking **"Valid Releases"** or **"Support Packages"** — the version data may appear under a different label.
- If SAP for Me shows a login wall, run `playwright-cli attach --cdp=msedge` to reuse the existing authenticated Edge session.
- The Excel file is updated in-place — the original columns A-D are preserved.
